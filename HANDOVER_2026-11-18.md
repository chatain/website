## 2. How to work on the site

1. Edit under `OC251010/website/`.
2. Build with `~/.local/bin/hugo-0.162.1 --gc --minify` and check that the build has no `ERROR`.
3. Commit, push, then wait for the deploy (`gh run watch <id> -R chatain/website --exit-status`).
4. **Check the live site** with `curl`: the page or PDF should return 200 and contain the change. A
   successful push is not proof that the change is live.
5. Add an entry to the change log in `OUTSTANDING.md`.

**Push only when the researcher says so** while they are still revising a file (see §5, 12 Nov).

## 5. Things that will catch you out

- **PDFs go in `static/uploads/`, never `public/`.** `public/` is build output, deleted on every build and
  ignored by git. Getting this wrong broke 4 PDFs for months.
- **Where the PDFs come from:**
  - Meta/Google note: Dropbox `…/Undersea Network/Cables/Lab/Prototype 20260115-claude/Popular Writing/Drafts/latex_IRSEM_v11_261014/IRSEM_note_v13.{tex,pdf}`. That folder is in git repo `chatain/subsea-cable`, which has its own `CLAUDE.MD` and session-log rules.
  - Value Capture WP: `Research/Projects/Value Capture Theory/LaTeX/Chatain - Value Capture WP 2025.{tex,pdf}`.
    **Another tool works in this folder.** It deletes auxiliary and backup files, and it keeps its
    own `AGENTS.md` and `LOG.md`. That folder is not in git. Don't edit there while the researcher says the
    other tool is working, and re-check each new PDF before copying it (§2).
  - The site keeps stable filenames (`Chatain-2026-…pdf`), so links stay valid when a PDF is swapped.
- **Checks to run on a new PDF before publishing:**
  - stray `( ` after an opening parenthesis;
  - glued names such as `StuartJr.`;
  - `??`, `TODO` and raw citation keys;
  - undefined references in the `.log`;
  - the reference list compared with the live PDF's;
  - a word diff against the live PDF.
- **Domain:** the GitHub Pages custom-domain setting (`olivierchatain.com`) is what counts. With Actions
  deploys the `CNAME` file is ignored (it is kept in sync only for clarity).
- **SSRN** blocks `curl`/automated fetches (Cloudflare). Verify SSRN papers through Crossref DOIs instead.
- **CI build machines** move to Ubuntu 26 (announced for October 2026). Builds have passed so far.
- **Shell:** zsh treats `echo ===` as an error. Use `echo '---'`.
